# 🏎️ Pit Wall - GP de São Paulo

Uma landing page moderna, responsiva e temática inspirada na Fórmula 1, focada na divulgação e venda de ingressos para o **GP de São Paulo em Interlagos**.

---

## 📌 Sobre o Projeto

O **Pit Wall** é um projeto desenvolvido para praticar e consolidar conceitos de desenvolvimento web frontend com **HTML5** e **CSS3**. A página apresenta a atmosfera de um fim de semana de corrida da F1, destacando estatísticas do circuito, os principais pilotos do grid, a classificação do campeonato e um formulário para reserva de ingressos.

---

## 🎨 Funcionalidades e Destaques

- **Header Fixo (Topbar):** Navegação fluida com links de ancoragem e botão de chamada para ação (*CTA*).
- **Hero Section com Mídia Personalizada:** 
  - Layout em grid com estatísticas reais do circuito de Interlagos (71 voltas, 4.309 km/volta, 15 curvas).
  - Design com efeito diagonal inclinado e barra zebrada (*kerb*) temática da F1.
- **Grid de Pilotos:** Cards estilizados com variáveis CSS para personalização das cores de cada equipa.
- **Tabela de Classificação:** 
  - Filtros para pesquisa por nome e equipa.
  - Tabela com estilização especial para o líder do campeonato e oculta colunas secundárias em dispositivos móveis.
- **Seção de Ingressos:** 
  - Tabela de preços e aviso de disponibilidade.
  - Formulário completo com suporte a upload de ficheiro, dados de perfil, data e mensagem para o piloto.
- **Design Responsivo:** Adaptado para telemóveis e ecrãs menores através de *media queries*.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do projeto (`<header>`, `<section>`, `<form>`, `<table>`, `<footer>`).
- **CSS3:** 
  - CSS Grid e Flexbox para layouts complexos.
  - Variáveis CSS (`--cor-piloto`) para dinamismo nas cores.
  - Transições e efeitos de hover.
  - *Media Queries* para responsividade mobile.
- **Google Fonts / Segoe UI:** Tipografia limpa e moderna.
